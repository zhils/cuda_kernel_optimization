⚡ 优化技术速查表

本项目涉及的全部 CUDA 优化技术一览

技术 类别 使用位置 说明
Shared Memory Tiling Memory GEMM V1 将数据分块加载到共享内存 (SMEM)，在块内多次复用，减少全局内存访问
Bank Conflict Avoidance Memory GEMM V2 [TILE][TILE+1] padding，错开 bank 映射消除共享内存 bank 冲突
__ldg() Read-Only Cache Memory GEMM V2 通过纹理缓存路径读取只读数据，减少 L1 cache 压力
float4 Vectorized Access Memory RMSNorm V2, Softmax V3 128-bit 内存事务，单条指令加载 4 个 float，提升带宽利用率
__restrict__ Memory All Kernels 告诉编译器指针无别名，启用更激进的优化（常量传播、寄存器分配）
#pragma unroll Compute GEMM V2 编译器循环展开，消除循环开销，增加指令级并行
Thread-Level Tiling Compute GEMM V3 每线程计算 4×4 输出，结果留在寄存器，减少 SMEM 读取次数
Warp Shuffle (__shfl_sync) Compute Softmax V3, RMSNorm V1–V3 warp 内线程直接交换寄存器数据，无需 SMEM 中转，延迟更低
Online Algorithm Algorithm Softmax V2 单遍同时计算 max 和 sum，减少一趟内存扫描（3→2 pass）
Kernel Fusion Algorithm RMSNorm V3 将归约和输出写入融合到单个 kernel，消除中间全局内存读写
Tensor Core (WMMA) Hardware GEMM V4 使用 wmma::mma_sync 调用硬件矩阵乘累加单元，吞吐量数量级提升
__fmul_rn Intrinsics Hardware RMSNorm V3 使用硬件 round-to-nearest 乘法，确保浮点确定性，避免编译器 FMA 合并

🔧 构建与运行指南

1

构建项目

mkdir build && cd build
cmake .. -DCMAKE_CUDA_ARCHITECTURES=120
make -j$(nproc)
2

运行单个 Kernel（适合 Nsight 逐一分析）

cd .. # 回到项目根目录
./build/bin/gemm_v0_naive
./build/bin/gemm_v2_thread_tiling
./build/bin/softmax_v3_warp_shuffle
./build/bin/rmsnorm_v2_vectorized
3

运行对比 Benchmark

./build/bin/gemm_benchmark_all
./build/bin/softmax_benchmark_all
./build/bin/rmsnorm_benchmark_all
4

Nsight Compute 性能分析

ncu --set full ./build/bin/gemm_v0_naive
ncu --set full ./build/bin/gemm_v2_thread_tiling
提示：使用 ncu 需要 root 权限或在 /etc/modprobe.d/ 中配置 NVreg_RestrictProfilingToAdminUsers=0。 建议先用 --target-processes all 确认 kernel 可被正确捕获。
